# Welcome to your SidekickDB NextJS app 👋

[SidekickDB Docs](https://sidekickdb.co/docs)
[NextJS Docs](https://nextjs.org/docs)

This is a NextJS project scaffolded with create-sidekick-app.

To run the development server:
`npm run dev`

To push schema changes:
`npx @sidekickdb/cli push`

To pull schema changes:
`npx @sidekickdb/cli pull`


Got any feedback or questions? Open an issue on [GitHub](https://github.com/SidekickDB/sidekick/issues)
