# Welcome to your SidekickDB Bun + React app 👋

To run the development server:
`bun run dev`

To push schema changes:
`bunx --package=@sidekickdb/cli sidekick-cli push`

To pull schema changes:
`bunx --package=@sidekickdb/cli sidekick-cli pull`

Got any feedback or questions? Join our [Discord](https://discord.gg/hgVf9R6SBm)
